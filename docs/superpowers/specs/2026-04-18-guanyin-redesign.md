# 观音灵签页面重新设计方案

## 概述

本文档描述观音灵签页面的完整重新设计，重点还原真实签筒签条，优化UI布局和融合感。

## 1. 签筒本体设计

### 1.1 三层粒子结构

**筒壁轮廓层**
- 粒子颜色范围：#991a1a ~ #cc2222（深红色渐变）
- 粒子密度：高密度，勾勒圆柱轮廓
- 圆柱参数：
  - 顶部半径：1.5
  - 底部半径：1.2
  - 高度：3.5
  - 粒子数量：约1200个

**筒内填充层**
- 粒子颜色：中密度暗红色（#661111 ~ #881111
- 粒子密度：中密度，填充签筒内部
- 粒子数量：约800个

**高光效果层**
- 粒子颜色：亮红色（#ff3333）和白色（#ffffff）
- 位置：顶部和正面区域
- 粒子数量：约200个
- 粒子尺寸：比筒壁粒子稍大

### 1.2 烫金"签"字

- 颜色：金黄色（#ffd700）
- 实现方式：按"签"字笔画轨迹排布粒子
- 粒子特性：比筒壁粒子更亮、更大（size约1.5倍）
- 位置：签筒正面居中
- 粒子数量：约300个

## 2. 签条部分设计

### 2.1 签条形态

- 形状：细长矩形粒子
- 比例：长:宽 ≈ 15:1
- 粒子数量：每根签条约60-80个粒子
- 总签条数：14-16根

### 2.2 签条布局

- 底部固定在签筒内
- 顶部随机高出签筒5%-15%（不要全部齐平）
- 随机轻微倾斜（±5°）

### 2.3 层次感

- **前后分层**：
  - 靠前的签条：偏白的亮色粒子（#f5f5f5 ~ #ffffff）
  - 靠后的签条：偏红的暗色粒子（#e8d0d0 ~ #d4a0a0）
- **Z轴排序**：根据签条角度分配Z轴深度

### 2.4 密度要求

- 签条粒子密度：比背景粒子高3倍以上
- 粒子尺寸：稍大于背景粒子

### 2.5 烫金签号

- 选择3-5根靠前的签条
- 用金黄色粒子（#ffd700）
- 在签条上半部分绘制"第X签"文字
- 文字样式："第一签"、"第八十五签"等

## 3. 背景粒子效果设计

### 3.1 整体原则

- 背景不抢戏、有氛围
- 纯黑色背景

### 3.2 弱对比星空效果

**粒子形态**
- 纯圆形粒子
- 带轻微羽化模糊
- 与签条的长条状粒子形态完全区分开

**亮度控制**
- 粒子亮度：签条亮度的15%-25%，最高不超过30%
- 中心区域更暗：签筒中心区域背景粒子亮度降低30%
- 边缘区域稍亮：形成自然的视觉聚焦效果

**粒子参数**
- 数量：300-500个
- 直径：1-2px
- 透明度：0.2-0.5
- 动画：缓慢呼吸动画（透明度0.2→0.5循环）
- 动画周期：约3-4秒

### 3.3 CCD复古噪点滤镜

- 透明度：0.15-0.2
- 模拟颗粒质感
- 不影响主体可见度
- 实现方式：Three.js后期处理或Canvas overlay

## 4. 输入框与按钮布局设计

### 4.1 整体布局

- **位置**：页面底部居中
- **样式**：通栏长条状半透明毛玻璃容器
- **原则**：不遮挡签筒主体

### 4.2 毛玻璃效果

```css
backdrop-filter: blur(16px) saturate(130%);
background: rgba(15, 15, 30, 0.65);
border: 1px solid rgba(255, 255, 255, 0.1);
```

### 4.3 模块结构（从左到右）

**1. 输入框**
- 半透明背景，与页面整体背景融合
- 颜色不突兀
- 带轻微边框
- 文字颜色：白色
- placeholder文字：柔和不突兀（rgba(255,255,255,0.5)

**2. 「手势控制」按钮**
- 颜色与整体背景融合不突兀
- 半透明设计

**3. 「鼠标控制」按钮**
- 颜色与整体背景融合不突兀
- 半透明设计

### 4.4 按钮动效

- hover时上浮效果（translateY: -2px）
- hover时阴影效果
- 不做任何生硬的纯色块或直角设计
- 圆角设计

## 5. 整体动画设计

### 5.1 签筒呼吸动画

- 缓慢的上下呼吸
- 幅度：约0.1-0.15单位
- 周期：约2-3秒
- easeInOut easing

### 5.2 签条随机晃动

- 微小随机晃动
- 每根签条有独立的晃动相位
- 幅度：约±0.03单位
- 频率：每根签条略有不同

## 6. 技术实现要点

### 6.1 Three.js相关

- 使用@react-three/fiber和@react-three/drei
- PointsMaterial用于粒子渲染
- AdditiveBlending用于发光效果
- 后期处理用于噪点滤镜

## 7. 验收标准

1. 签筒具有真实红漆签筒的视觉效果，三层粒子结构分明
2. 签条有立体感，前后层次清晰，烫金文字清晰可见
3. 背景星空柔和不抢戏，中心区域自然聚焦
4. 底部控件布局合理，毛玻璃效果融合自然
5. 整体动画流畅自然，不生硬
6. 所有功能正常（手势控制、鼠标控制、抽签流程）
