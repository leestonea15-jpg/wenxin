# 问心 - UI/体验优化迭代需求文档

**迭代名称**：问心MVP UI/体验优化迭代  
**迭代日期**：2026-04-08  
**版本**：v1.0 → v1.1

---

## 一、背景与目标

当前MVP版本存在一些体验问题需要优化，包括：文案表述、页面排版、视觉风格、图标质感、以及测算仪式感的增强。

**目标**：提升整体视觉质感和用户体验，让产品更面向年轻用户群体，同时增强测算的仪式感。

---

## 二、需求详情

### 需求1：首页文案优化

| 项 | 内容 |
|---|---|
| **当前** | Section标题："选择玩法" |
| **修改为** | Section标题："选择模式" |
| **备注** | 副标题保持不变："多种测算方式，满足你不同的需求" |

---

### 需求2：首页卡片布局优化

| 项 | 内容 |
|---|---|
| **问题** | 4列布局在宽屏上卡片贴边，且位置偏下 |
| **方案** | 改为2x2网格布局，所有屏幕最大显示2列 |
| **具体修改** | `grid grid-cols-1 md:grid-cols-2 gap-8`，移除`lg:grid-cols-4`；容器保持`max-w-6xl`，Section padding改为`py-16` |
| **验收标准** | 卡片左右留白充足，不拥挤，不贴边，整体排版美观 |

---

### 需求3：产品Logo设计

| 项 | 内容 |
|---|---|
| **风格** | 融合风格（传统元素+现代简约），面向年轻用户，避免老气 |
| **样式** | 简约圆形轮廓，内部是现代字体设计的"问"字变形 |
| **颜色** | 现代金色渐变（暖金到淡香槟金） |
| **使用位置** | 1. 首页Hero区域（大尺寸，约80-100px）；2. 导航栏左侧（小尺寸，约32px，配合"问心"文字） |

---

### 需求4：每日速测卡片配色优化

| 项 | 内容 |
|---|---|
| **问题** | 金钱卦灰色底色显得像不可用，与掷圣杯不协调 |
| **金钱卦** | 改为金色渐变：`bg-gradient-to-br from-yellow-50 to-amber-100` |
| **掷圣杯** | 调整为红暖色调：`bg-gradient-to-br from-orange-50 to-red-100` |
| **验收标准** | 两个卡片都属暖色系，协调且有区分度，金钱卦不再显得像禁用状态 |

---

### 需求5：图标替换为SVG

| 项 | 内容 |
|---|---|
| **金钱卦图标** | 替换为SVG绘制的乾隆通宝：圆形方孔，带"乾隆通宝"四字（顺时针或上下右左排列），金色古铜质感但不过于旧 |
| **掷圣杯图标** | 替换为SVG绘制的圣杯：两个月牙形（半月形）木块相对摆放，传统朱红色/红木色，用简单线条表现木质纹理 |
| **实现** | 新建`src/components/icons/`目录，分别创建`QianlongTongbao.tsx`和`Shengbei.tsx`组件 |
| **尺寸** | 在卡片中显示约64px |

---

### 需求6：测算冷却机制（仪式感增强）

| 项 | 内容 |
|---|---|
| **背景** | 增强测算仪式感，一卦一问方显诚 |
| **规则** | 测算完成后，30秒内再次点击任意测算会触发冷却提示 |
| **交互逻辑** | 1. 按钮**不预先禁用**，保持可点击状态（用户可能测完就离开，不需要一直显示禁用）；2. 点击时检查距离上次测算是否&lt;30s；3. 若&lt;30s：在按钮附近显示气泡提示，不打开弹窗；4. 若&gt;=30s或首次使用：正常打开弹窗，测算完成（显示结果时）更新时间戳为`Date.now()` |
| **提示文案** | "一卦一问方显诚，心定再卜，请静心等候 Xs"（X为剩余秒数） |
| **提示位置** | 点击的按钮附近气泡提示，显示2-3秒后自动消失 |
