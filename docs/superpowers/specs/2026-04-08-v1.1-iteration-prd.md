**迭代名称**：问心 v1.1 - UI优化 + 手势控制  
**迭代日期**：2026-04-08  
**版本**：v1.0 → v1.1

---

## 一、背景与目标

### 背景
当前MVP版本存在两点主要问题：
1. UI/体验细节有待优化（文案、排版、配色、图标等）
2. 缺少手势控制功能，这是之前规划中的核心交互方式

### 目标
- 提升整体视觉质感和用户体验，让产品更面向年轻用户群体
- 实现手势控制功能，通过摄像头识别手势来进行测算，增强产品吸引力和体验感
- 完善的降级方案，确保在摄像头不可用时仍能正常使用

### 需求6：测算冷却机制（仪式感增强）

| 项 | 内容 |
|---|---|
| **背景** | 增强测算仪式感，一卦一问方显诚 |
| **规则** | 测算完成后，30秒内再次点击任意测算会触发冷却提示 |
| **交互逻辑** | 1. 按钮**不预先禁用**，保持可点击状态（用户可能测完就离开，不需要一直显示禁用）；2. 点击时检查距离上次测算是否&lt;30s；3. 若&lt;30s：在按钮附近显示气泡提示，不打开弹窗；4. 若&gt;=30s或首次使用：正常打开弹窗，测算完成（显示结果时）更新时间戳为`Date.now()` |
| **提示文案** | "一卦一问方显诚，心定再卜，请静心等候 Xs"（X为剩余秒数） |
| **提示位置** | 点击的按钮附近气泡提示，显示2-3秒后自动消失 |

### 需求7：手势控制功能（核心需求）

#### 7.1 整体流程

**金钱卦流程：**
1. 用户点击"开始测算" → 申请摄像头权限
2. 摄像头打开 → 画面上叠加显示3枚铜钱图案（静态）
3. 文字提示："请做「摇铜钱」手势：手握拳，在胸前上下或左右摇晃（就像手里握着铜钱在摇一样）" + 简笔画手势示意图
4. 用户做手势 → 提示变为"识别中..."
5. 识别成功 → 3枚铜钱开始做摇晃/旋转动画
6. 动画结束 → 显示结果（3枚铜钱正反面 + 吉凶结果）

**掷圣杯流程：**
1. 用户点击"开始测算" → 申请摄像头权限
2. 摄像头打开 → 画面上叠加显示一对圣杯图案（静态）
3. 文字提示："请做「抛圣杯」手势：手掌向上，从下往上挥（就像把圣杯向上抛起一样）" + 简笔画手势示意图
4. 用户做手势 → 提示变为"识别中..."
5. 识别成功 → 圣杯做抛起落下动画
6. 动画结束 → 显示结果

#### 7.2 摄像头权限与引导

| 项 | 内容 |
|---|---|
| **权限申请时机** | 点击"开始测算"后，打开Modal时申请摄像头权限 |
| **权限被拒绝时** | 显示友好提示，告知用户可以使用点击方式继续，或去设置中开启权限 |
| **引导界面** | 摄像头打开后，显示简易引导：告知用户应该做什么手势，画面中显示手势识别区域 |

#### 7.3 手势定义

**金钱卦手势：**
- **手势名称**：摇铜钱
- **动作描述**：手握拳，上下或左右摇晃（模拟摇铜钱的动作）
- **触发条件**：识别到摇晃动作并持续1-2秒
- **效果**：触发铜钱动画，然后显示结果

**掷圣杯手势：**
- **手势名称**：抛圣杯
- **动作描述**：手从下往上挥（模拟抛起圣杯的动作）
- **触发条件**：识别到上挥动作
- **效果**：触发圣杯动画，然后显示结果

#### 7.4 技术方案

| 项 | 内容 |
|---|---|
| **手势识别库** | MediaPipe Hands（轻量级，浏览器端运行，无需后端） |
| **摄像头调用** | WebRTC API `navigator.mediaDevices.getUserMedia` |
| **实现位置** | 新建 `src/hooks/useGestureControl.ts` 封装手势识别逻辑 |
| **状态管理** | 在Modal内管理：摄像头状态、识别状态、手势提示 |

#### 7.5 降级方案（重要）

| 场景 | 降级方案 |
|---|---|
| 浏览器不支持摄像头/WebRTC | 隐藏手势模式，直接使用点击方式（和v1.0一样） |
| 用户拒绝摄像头权限 | 显示提示，提供"使用点击方式"按钮，切换回点击模式 |
| 摄像头可用但连续3次识别失败 | 提示用户"手势识别不太顺利"，提供"改用点击方式"按钮 |
| **保留点击模式** | 即使摄像头可用，也始终保留"点击开始"的备选方式（放在手势区域下方） |

#### 7.6 UI界面

**手势测算Modal布局：**
- 上半部分：摄像头画面（全屏或区域显示）
  - 画面上叠加：道具图案（3枚铜钱 或 一对圣杯，静态）
  - 画面角落：简笔画手势示意图（提示用户该做什么手势）
- 中间区域：
  - 状态文案（多行，清晰说明）：
    - 等待时：详细手势说明 + 动作描述
    - 识别中："识别中..."
    - 识别成功："识别成功！"
- 下半部分：备选按钮"点击开始"（始终可用，放在最下方）

**道具动画：**
- 识别成功后，画面上的静态道具变为动画：
  - 铜钱：摇晃/旋转动画
  - 圣杯：抛起落下动画
