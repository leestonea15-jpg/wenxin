# 问心 - 运势测算网站

每一次对命运的探索和好奇，都源自于内心对自我了解的渴望。

## 技术栈

- 前端: React + Vite + Tailwind CSS
- 后端: FastAPI + SQLAlchemy
- 数据库: Supabase PostgreSQL
- 认证: Supabase Auth

## 开发

### 前端

```bash
cd frontend
npm install
npm run dev
```

### 后端

```bash
cd backend
pip install -r requirements.txt
python main.py
```
